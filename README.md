# 日本史学習アプリ（静的PWA版）

日本史（高校・中学）の学習アプリです。問題演習・単元テキスト・用語辞書・年号カードなどを収録し、スマートフォンにインストールして使えます。

## 使い方

公開ページ: https://otodesk4193.github.io/japanese-history-db/app/

- **Android**: Chrome で開く → メニュー（︙）→「アプリをインストール」
- **iPhone**: Safari で開く → 共有 →「ホーム画面に追加」

インストール後はオフラインでも使えます。学習記録は端末内にのみ保存されます。

## 収録内容

- 高校日本史 問題538問 / 中学日本史 問題200問
- 単元テキスト14本（年表・語呂・資料つき）、模範解答の解説31件
- 用語辞書1,895語、年号カード247件、世界年表127件、豆知識60件、図解19点
- 模試モード（32問・制限時間なし）、間隔反復による復習、全体検索
